📘 Documentation: Client.java
Overview
The Client class is a simple UDP-based discovery client designed to broadcast its presence over a local network and listen for other active clients. It uses multithreading to handle broadcasting and listening simultaneously.

⚙️ Class Overview
public class Client {
    private static int BROADCAST_PORT = 8888;
    private static final int INVITE_PORT = 8889;
    private static final UUID uuid = UUID.randomUUID();
    private static final String BROADCAST_ADDRESS = "255.255.255.255";
}
Fields:
    • BROADCAST_PORT (default 8888):
Used for sending and receiving “HELLO” broadcast packets that announce a client’s presence on the local network.
    • INVITE_PORT (8889):
Intended for direct invitations or chat requests between clients.
    • uuid (randomly generated):
Unique identifier for each client instance. Used to filter out self-broadcast messages.
    • BROADCAST_ADDRESS ("255.255.255.255"):
Universal IPv4 broadcast address used to send packets visible to all devices on the same network subnet.

4. Continuous Broadcast Loop
while (true) {
    InetAddress broadcastAddress = InetAddress.getByName(BROADCAST_ADDRESS);
    DatagramPacket sendPacket = new DatagramPacket(
        message.getBytes(),
        message.length(),
        broadcastAddress,
        BROADCAST_PORT
    );
    helloSocket.send(sendPacket);
    System.out.println("Broadcast sent: " + message);
    Thread.sleep(3000);
}
Behavior:
    • Sends the HELLO message to all devices on the network (via 255.255.255.255) every 3 seconds.
    • Uses a DatagramPacket to encapsulate the data.
    • The Thread.sleep(3000) introduces a delay to prevent network flooding.
